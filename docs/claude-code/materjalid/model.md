# `/model`

`/model` avab mudeli valiku ja näitab aktiivset mudelit.

```text
/model
```

Mudelite erinevus on peamiselt kiiruses ja võimekuses. Lihtsa ülesande jaoks piisab kiiremast mudelist, keerulisema analüüsi jaoks vali võimekam mudel.

Võimekam mudel võib kasutuslimiiti või krediite kiiremini kulutada. Sonnet on siin võrdluse alus:

| Mudel | Sobib | Suhteline kasutus |
|---|---|---|
| Sonnet | Igapäevased ülesanded | 1× |
| Opus | Keerukamad ülesanded | ~2× võrreldes Sonnetiga |
| Fable | Kõige raskemad ja pikemad ülesanded | Vajab usage credit'eid |

- `Enter` — salvesta mudel uute sessioonide vaikimisi valikuks.
- `s` — kasuta mudelit ainult praeguses sessioonis.
