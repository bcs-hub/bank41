# `/mcp`

Avab Claude Code'is MCP serverite halduse.

```text
/mcp
```

Menüüs saab:

- vaadata ühendatud servereid ja nende olekut;
- näha serveri pakutavate tööriistade arvu;
- teha OAuth-autentimist;
- autentimise eemaldada.

Uue serveri lisamiseks kasutatakse terminalis `claude mcp add` käsku. Seejärel kontrolli ühendust `/mcp` menüüst.
