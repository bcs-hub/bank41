# `Shift+Tab` — permission mode

`Shift+Tab` vahetab Claude Code'i tegutsemisrežiimi. Aktiivne režiim on näha promptirea all.

- **Manual** — Claude loeb küsimata, kuid küsib enne muudatusi ja enamikku käske luba.
- **Accept edits** — faili- ja tavapärased kaustamuudatused tehakse küsimata.
- **Plan** — Claude uurib projekti ja koostab plaani, kuid lähtekoodi ei muuda.
- **Auto mode** — Claude tegutseb vähemate küsimustega ja tegevusi kontrollib taustal turvamudel.

[`/permissions`](permissions.md) reeglid kehtivad ka režiimide vahetamisel. `Deny` on alati tugevam kui `Allow`. Sellest räägime peagi täpsemalt.
