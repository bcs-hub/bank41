# Töötoa eesmärk ja ülesehitus

## Eesmärk

Õpime Claude Code'i võimalusi praktiliselt kasutama olemasolevas tarkvaraprojektis.
Eesmärk ei ole projekt valmis teha, vaid arendada selle valitud osi ning harjutada nende
kaudu Claude Code'iga planeerimist, koodi muutmist ja tulemuse kontrollimist.

## Projekt

Harjutused põhinevad Vali-IT pangaautomaatide asukoha projektil:

- Vue.js frontend;
- Java ja Spring Boot backend;
- lokaalne PostgreSQL andmebaas `vali_it`.

## Ülesehitus

1. Tutvume projekti ja Claude Code'iga.
2. Anname Claude Code'ile projekti konteksti.
3. Planeerime ja lahendame arendusülesandeid.
4. Kontrollime tehtud muudatusi.
5. Tutvume skillide ja MCP-ga.
