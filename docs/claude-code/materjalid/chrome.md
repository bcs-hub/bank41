# `/chrome`

Ühendab Claude Code'i Chrome'i laiendusega, et Claude saaks brauserit kasutada.

```text
/chrome
```

Vajalikud on **Claude in Chrome** laiendus ja Chrome või mõni teine Chromiumi-põhine brauser.

## WSL-i piirang

Claude in Chrome ei ole WSL-is toetatud. Probleem on WSL-i toes, mitte ainult selles, et Chrome on paigaldatud Windowsi.

**Workaround:** ava projekti kaust Windowsi Command Promptis või PowerShellis, käivita sinna paigaldatud Claude Code ja kasuta `/chrome` käsku seal.
