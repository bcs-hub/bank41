# Projekti idee

Töötoa praktiline projekt on Vali-IT programmi pangaautomaatide asukohtade õppeprojekt,
mida kasutatakse programmeerimise õppimiseks. Selles töötoas kasutame tuttavat projekti
Claude Code'i võimaluste ja töövõtete harjutamiseks.

Klient saab rakenduses:

- vaadata kõiki pangaautomaatide asukohti;
- filtreerida asukohti linna järgi;
- avada asukoha detailvaate;
- näha automaatide arvu ja pakutavaid tehinguid, näiteks raha sisse- ja väljamakset;
- näha asukoha pilti ja koordinaate.

Administraator saab lisada uusi pangaautomaatide asukohti koos linna, automaatide arvu,
tehingutüüpide, koordinaatide ja pildiga.

Rakendus koosneb Vue frontendist, Spring Boot REST API-st ja PostgreSQL-i andmebaasist.
Töötoa alguses ei ole kogu rakendus valmis: osalejad ehitavad funktsionaalsust järjestikuste
ülesannetega ning iga järgmine ülesanne jätkab eelmise tulemusest.
