# PDF-ist Markdowni skill

Eesmärk on luua Notepadis lihtne skill, mis muudab PDF-taski Markdown-failiks.

Skill peab:

1. küsima kasutajalt PDF-faili rada;
2. lugema PDF-ist taski sisu;
3. looma taskist selge `.md` faili.

Katseta skilli kolme PDF-taskiga:

- FEB-7 – Login koos rolliga;
- BEB-5 – Login koos rolliga;
- BEB-6 – Linnade info.

Kontrolli iga tulemuse puhul, et olulised nõuded, vastuvõtukriteeriumid ja tehniline info
oleksid Markdown-failis alles.
