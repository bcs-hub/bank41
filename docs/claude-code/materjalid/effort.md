# `/effort`

`/effort` määrab mudeli arutlemise põhjalikkuse.

```text
low  →  medium  →  high  →  xhigh  →  max
kiirem ja väiksem kasutus  →  põhjalikum ja suurem kasutus
```

Lihtsa ülesande jaoks vali madalam, keerulise jaoks kõrgem tase. `auto` kasutab mudeli vaikimisi taset.

Muuda taset käsuga `/effort` või `/model` vaates `←` ja `→` klahvidega. Võimalikud tasemed sõltuvad mudelist.
