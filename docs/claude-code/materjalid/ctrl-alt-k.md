# `Ctrl+Alt+K`

Lisab JetBrains IDE-s aktiivse faili või valitud read Claude Code'i prompti.

```text
@backend/src/main/java/Bank.java#L10-25
```

Vajab Claude Code'i IDE pluginat. Vajaduse korral ühenda Claude Code IDE-ga käsu `/ide` abil.

Macis kasuta `Cmd+Option+K`.

## Valitud kood

IDE-s valitud read jagatakse Claude Code'iga automaatselt ka ilma klahvikombinatsioonita.

> Claude võib sõnumist ise aru saada, et mõtled valitud ridu, kuid mitte alati. Kui valik on oluline, viita sellele promptis või lisa see `Ctrl+Alt+K` abil.
