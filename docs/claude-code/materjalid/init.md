# `/init`

Käivita projekti juurkaustas:

```text
/init
```

Claude Code analüüsib projekti ja loob selle põhjal esialgse `CLAUDE.md` faili.

Faili võivad jõuda näiteks:

- projekti struktuur;
- build'i ja testide käsud;
- kasutatavad tehnoloogiad;
- koodi kirjutamise kokkulepped.

Kui `CLAUDE.md` on juba olemas, pakub `/init` selle täiendusi ega kirjuta faili lihtsalt üle.

Vaata tulemus alati üle ning jäta alles ainult projekti jaoks vajalikud juhised.

Vaatame näidet harus `master-vanilla`.
