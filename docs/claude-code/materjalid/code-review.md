# `/code-review`

`/code-review` vaatab tehtud koodimuudatused üle ning otsib võimalikke vigu, regressioone
ja muid probleeme.

Oluline teada:

- käivita see pärast implementatsiooni ja teste;
- vaata leiud ise üle, sest kõik soovitused ei pruugi olla õiged ega vajalikud;
- käsk võib tulla pluginast ja ei pruugi igas Claude Code'i paigalduses olemas olla;
- Claude Code'i sisseehitatud sarnane käsk on `/review`.
