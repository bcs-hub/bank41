# `/simplify`

`/simplify` vaatab hiljuti muudetud failid üle ning otsib võimalusi muuta kood lihtsamaks,
taaskasutatavamaks ja tõhusamaks.

Oluline teada:

- käsk võib parandused automaatselt failidesse rakendada;
- vaata pärast käsku Git diff üle;
- käivita testid uuesti;
- ära võta kõiki muudatusi vastu ainult sellepärast, et kood muutus lühemaks.
