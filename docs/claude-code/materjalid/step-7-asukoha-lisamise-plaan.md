# STEP-7 – Asukoha lisamise plaan

Eesmärk on koostada esmalt Notepadis plaani lähteülesanne ja anda seejärel ülesanne Claude
Code'ile `/plan` mode'is analüüsimiseks.

[Ava Basic mock-piltide kaust](../../mock/png/basic/)

Kasuta sisendina kolme pilti:

- `STEP-7 (Askoha lisamine) - tühi.png`;
- `STEP-7 (Askoha lisamine) komponentide raamid.png`;
- `STEP-7 (Askoha lisamine) success message.png`.

Kasuta faili [`docs/architecture/openAPI.json`](../../architecture/openAPI.json), et
kontrollida asukoha lisamise `POST /api/atm/location` lepingut.

Kirjuta Notepadis esialgne ülesanne, mis viitab piltidele ja OpenAPI lepingule. Käivita
Claude Code'is `/plan`, anna ülesanne sisse ning vaata loodud plaan enne implementatsiooni
üle.
