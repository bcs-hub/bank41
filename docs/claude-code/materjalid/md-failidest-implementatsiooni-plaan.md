# Markdown-failidest implementatsiooniplaan

Eesmärk on luua Notepadis lihtne skill, mis koostab mitme `.md` taskifaili põhjal ühise
implementatsiooniplaani.

Skill peab:

1. küsima kasutajalt `.md` taskifailide rajad;
2. lugema kõigi taskide nõuded;
3. leidma frontend- ja backend-taskide seosed;
4. koostama tööde järjekorraga ühe implementatsiooniplaani.

Katseta skilli FEB-7 ja BEB-5 Markdown-failidega.

Kontrolli, et plaan arvestaks mõlema taski nõuetega ning jagaks töö väikesteks ja loogilises
järjekorras sammudeks.
