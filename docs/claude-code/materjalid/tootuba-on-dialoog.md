# Töötuba on dialoog

- Kõik küsimused ja kommentaarid on oodatud.
- Küsimuse või mõtte korral hõika lihtsalt vahele.
- Suhtleme eelkõige mikrofoni kaudu.
- Vestlusakent ei pruugi töötoa ajal jõuda jälgida.
- Vestlusakent võite siiski kasutada omavahel suhtlemiseks ja info jagamiseks.
- Proovime väga pikki vestlusi vältida, et püsida töötoa ajakavas.
