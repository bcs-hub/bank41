Padding ja margin:
ruum sees ja ruum väljas

Mõlemad tekitavad "tühja ruumi" elemendi ümber, aga täiesti erinevas kohas. Padding jääb kasti sisse — sisu ja serva vahele. Margin jääb kasti välja — kasti ja naabrite vahele.

Pildiraami analoogia padding = paspartuu raami sees · margin = vahe raamide vahel seinal

Katsuta ise: box model

Liiguta liugureid ja vaata, kuidas padding (sinine) ja margin (oranž) käituvad täiesti erinevalt. Pane tähele: taustavärv katab padding'u, aga margin jääb alati läbipaistvaks.

padding — sees, taustavärviga margin — väljas, läbipaistev
margin
sisu (tekst)

Padding suurendab valget/sinist ala sisu ümber — kast ise "paisub". Margin lükkab kogu kasti naabritest kaugemale, aga kasti enda suurus ei muutu.

Box model — kast kasti sees

Iga element koosneb neljast kihist, väljastpoolt sissepoole:

margin  → border → padding → sisu

Margin on alati läbipaistev — sellest "paistab läbi" see, mis on elemendi taga. Padding on osa elemendist endast, seega kui elemendil on taustavärv, laieneb see värv ka padding'i alale.

Koodinäide

.kast {
    background-color: lightblue;   /* näitab, kus kast lõpeb */
    padding: 20px;                  /* ruum SEES, sisu ja serva vahel */
    margin: 40px;                   /* ruum VÄLJAS, naabrite suhtes */
    border: 2px solid darkblue;
}

Lühivorm neljale küljele korraga järgib kellaosuti suunda, alustades ülevalt: 

padding: 10px 20px 10px 20px;   /* üles, paremale, alla, vasakule */
padding: 10px 20px;              /* üles/alla 10px, vasak/parem 20px */

Margin collapse — üllatus, mida tasub teada

Erinevalt padding'ust võivad kaks vertikaalset margin'it kokku sulada, kui nad puutuvad kokku — vahe ei ole nende summa, vaid suurem neist kahest. Vajuta nuppu ja vaata, kuidas kaks plokki käituvad.

Element A — margin-bottom: 30px
30px
Element B — margin-top: 20px

Vahe on 30px — suurem kahest väärtusest, mitte 50px summa.
